<h1 align="center">Anuva: open-source applicant tracking system (ATS)</h1>

---

**Anuva is an open-source applicant tracking system (ATS) for growing companies and recruiting teams.** It covers the full hiring flow: job posts, a careers site per company, candidate applications, CV screening with a transparent score, a pipeline board, interviews and scorecards, and offer letters signed online. You can use Anuva Cloud or host it yourself.

## What Anuva does

| Area | What you get |
| --- | --- |
| Jobs and careers site | Publish roles to `yourcompany.careers.anuva.io` or your own domain, with Google for Jobs structured data |
| Applications | Multi-step apply with knockout questions, consent capture and a candidate status portal |
| Screening | Weighted criteria and a cutoff decide the score, every override needs a written reason, and every decision is audited |
| Pipeline | Kanban board by stage, owners per job and candidate, team workload, interview scorecards |
| Offers | Structured offer letters, approvals and e-signature through Anuva Sign |
| Privacy and compliance | Database per tenant, Postgres row-level security, data subject requests, retention purge, tamper-evident audit log |
| Reports | Funnel, time to hire, source of hire and reply SLA |

## Who it is for

- **HR and talent teams** that want a modern ATS without per-seat lock-in
- **Recruiting agencies** that run hiring for several clients
- **Companies with data residency or security rules** that need to self-host candidate data

## Status

Anuva Cloud is in private beta with its first customers. The open-source core (AGPL-3.0) is being prepared for public release. Follow this organization to get notified when the repository opens.
